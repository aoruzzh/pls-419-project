### Independent audit · Yes

Run independently of the Ministry; results published yearly, including uncertainty.

### Data-quality flags · Yes, with review

Flags may only restore support; a caseworker confirms each; families are notified.

### Citizen explainer · Pilot only

Scale up only if a test shows high accuracy in Kazakh and more successful corrections or appeals.

Kazakhstan should not use AI to decide who is needy; it already has a rule for that. It should use AI to check whether the rule is right and to help people challenge it when it is not. If the government will not publish the points table or allow an independent audit, the honest answer is no: AI would only make an opaque system faster.
